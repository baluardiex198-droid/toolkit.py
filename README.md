# Network & OSINT Toolkit

A simple CLI utility written in Python for basic network intelligence gathering and footprinting.

## Features
- **IP Lookup**: Get geolocation and ISP details of any public IP address.
- **Port Scanner**: Check the status of common network ports on a target host.

## Installation & Usage

1. Clone the repository:
```bash
git clone https://github.com
cd network-toolkit
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the tool:
```bash
python toolkit.py
```
